# Meu-Primeiro-Projeto

# 🧮 Calculadora Web

Uma calculadora simples, moderna e responsiva desenvolvida com **HTML, CSS e JavaScript**.

## 📋 Sobre o projeto

Este projeto foi criado para praticar os fundamentos do desenvolvimento web, utilizando HTML para a estrutura, CSS para a estilização e JavaScript para a lógica e funcionamento da calculadora.

## ✨ Funcionalidades

* ➕ Adição
* ➖ Subtração
* ✖️ Multiplicação
* ➗ Divisão
* % Porcentagem
* ⌫ Apagar último número
* 🧹 Limpar calculadora
* ⌨️ Suporte ao teclado
* 📱 Design responsivo
* ⚠️ Tratamento de divisão por zero

## 🛠️ Tecnologias utilizadas

* **HTML5**
* **CSS3**
* **JavaScript**

## 📁 Estrutura do projeto

```text
calculadora/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 Como executar

### 1. Clone ou baixe o projeto

Baixe os arquivos do projeto para o seu computador.

### 2. Abra a pasta

Entre na pasta:

```text
calculadora/
```

### 3. Execute o projeto

Abra o arquivo:

```text
index.html
```

O projeto será aberto no seu navegador.

## ⌨️ Atalhos do teclado

A calculadora também pode ser utilizada pelo teclado:

| Tecla       | Função         |
| ----------- | -------------- |
| `0 - 9`     | Números        |
| `+`         | Adição         |
| `-`         | Subtração      |
| `*`         | Multiplicação  |
| `/`         | Divisão        |
| `%`         | Porcentagem    |
| `Enter`     | Calcular       |
| `Backspace` | Apagar         |
| `Esc`       | Limpar         |
| `.`         | Número decimal |

## 🎨 Interface

A calculadora possui uma interface escura com botões coloridos para facilitar a identificação das operações.
